Scoring & tier settings

Weights

Per-device completeness = Σ weights of non-empty tiered fields ÷ Σ weights of all tiered fields.

Values treated as empty

One per line. A cell that is blank after trimming is always treated as empty.

Exclude statuses from scoring

Devices with these statuses are shown but not scored (e.g. an empty BMC IP on a decommissioned server is not a data-quality problem).

Config export / import

Settings are saved automatically in this browser and restored on reload. Use export/import to move them to another machine.

Field tiers

Critical fields score with the critical weight and empty values are flagged red in the device table; important fields score with the important weight and empty values show a muted “empty” marker; ignored fields are excluded from scoring and their empty values are not marked.
